# v1.0.0 — Public reproducibility release

Initial public release supporting the manuscript “Representation-Matched q-Sensitivity: Rank Reversal and Decision Robustness in q-Rung Orthopair Fuzzy Models.”

The release contains the executable seven-case benchmark, the Qin/He analysis layer, radius-certificate replay metadata, directed upper-witness verification, and provenance/derived result files. Historical development files and third-party publisher materials are excluded.

The larger compressed retained cover trace is distributed with the companion Zenodo release rather than tracked in GitHub.
