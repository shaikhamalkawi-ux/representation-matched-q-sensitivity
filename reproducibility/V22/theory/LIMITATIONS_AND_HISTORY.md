# Qualifications retained in the public numerical scope

The successful six-decimal 16-row example does not erase the earlier fragile
seven-row example. In that separate construction, rounding the raw inputs to
six through nine decimal places did not retain the desired winner sequence.
The separate 18-instance ordinary-rounding study and its original timeout
history are diagnostics, not interval certificates. The full profile now replays
the S4 box/rounding results and the optimized S6 diagnostic, not the historically
timed-out uncached whole script. The full-history private working archive is
intentionally not made public. The S6 optimized 180-bisection body is unchanged;
252 finite literal equality probes supplement its operation-preserving cache
audit, not an exhaustive equivalence or continuum proof.

The separately transcribed 2022 Frank case is included only as qualified HTML
source reanalysis. Ordinary Decimal100 baseline scores do not all match the
printed values under nearest rounding. Post-hoc truncation compatibility does
not establish the authors' internal convention. The 74-node matched screen and
ordinary evaluated equal-weight limit show no sampled winner change; they do not
certify unobserved intervals or turn the article's fixed-raw sensitivity analysis
into a matched analysis. No source PDF is redistributed or claimed authenticated.

For the current 16-row example the integer nodes were selected by an ordinary
binary64 scan. That scan is discovery, not proof or held-out testing. The frozen
exact rational centre and subsequent directed full-box computations are what
support the displayed guarantee. The source JSON retains the discovery label;
the public runner uses only `verify`, never reselects nodes or silently shrinks
the requested box. Any failed requested-box attempt would remain in its result.

For Seikh's 2023 example the centre is the literal printed normalized matrix.
Its cost/benefit descriptions and swaps are not entirely unambiguous. Natural
logs and full, unrounded recomputed weights define the audited model. Using
the source's rounded three-decimal weights for the baseline is a different
convention; neither convention recovers unpublished source software. The exact
upper-witness JSON retains its heuristic search provenance, but its public replay
uses no optimizer and relies solely on feasibility and directed score tests.

The older public V18 lower enclosures are not substituted for the refined V22
S5 endpoints. Existing original kernels are reused unchanged; the refined
certificate trees and their exact-source pins identify what is now checked.
All finite q >= 4 is a mathematical coverage claim only for the stated uniform
Seikh source-radius certificate, not for every numerical illustration.

Malformed-record tests are deliberate negative software tests. A rejection is
not a new scientific counterexample. Ordinary derivative sampling in the fixed-q
audit checks implementation consistency; the interval tree, not sampling, is the
containing numerical argument. Directed arithmetic has been independently
implemented, but neither Python Decimal nor MPFR is proof-assistant verified by
this project.

No number of passed checks proves empirical prevalence, operator superiority,
universal precision sufficiency, journal suitability, revolutionary novelty or
human author/specialist approval. The analytic capacity/resource/Frank results
are reviewed as mathematics, not established by the finite certificate jobs.
