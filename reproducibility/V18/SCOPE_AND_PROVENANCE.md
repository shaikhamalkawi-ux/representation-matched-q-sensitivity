# Scope, provenance and limitations

## Included versus deliberately omitted

The public artifact includes the current Seikh integer/MPFR certificate module,
the seven-case benchmark, Qin/He structural and source checks, the historical
Qin q=3 cover and witness, Qin H/A unbounded-q and full-order covers, and the Zhang
control. It is not a complete copy of every development file or experiment.

The historical **30-record candidate-state ledger is unavailable**. Its absence
must not be concealed or confused with the recovered seven-row benchmark ledger.
No historical optimization campaign is claimed to have been freshly rerun.
The retained exact factor-11 one-dimensional example is an analytic argument in
the paper, not a claim about an unrestricted high-dimensional empirical radius.
The public release does not include publisher PDFs, a third-party Java archive,
class/JAR files, compiler/runtime binaries, personal or respondent-level records,
credentials, conversation history, or manuscript drafts.

## Original numerical sources

The benchmark's `SOURCE_REGISTER.csv`, case provenance notes and explicit source
comments identify the published examples. The small numerical arrays are inputs
to the authors' reimplementations, not re-distributed publisher articles.

The Seikh source-box computation starts from the **reproduced normalized**
baseline-raw matrix at r=4, not a new transcription and replay of every
pre-normalization source-table operation. Its coordinates, domain, center and
L-infinity metric differ from the historical canonical L2 experiments.
The immutable Seikh model input SHA-256 is:

`71351416bb73b22f3781bad962a023b6ea7362e8020429aab97b47d3f36d1797`.

The Qin H/A conventions retain shared Java local partition-size factors. H uses
the declared Hamacher final-merge convention, A the alternative source-code
merge convention. H is not claimed to agree literally with every printed
equation. The public artifact does not redistribute the source authors' Java
implementation, and no fresh original-Java execution is claimed here. The Qin
canonical L2 lower radius 0.000995 and upper witness are model H at q=3 only.
Use the freshly directed witness check for the outward upper-distance endpoint,
not the legacy `radius_upper_unchanged` metadata inherited in the old cover.

## Arithmetic and provenance boundary

Original scientific Python/C++ code and numerical records are copied
byte-for-byte, except the documented portable `analysis/kernel.py` loader. Its
platform/compiler selection was modernized; all mathematical wrapper functions
and the underlying C++ kernel are unchanged. New root launchers, documentation,
manifest checking and public QA summarize those existing scientific modules.

The Qin replay programs distinguish retained-binary replay from fresh validation
with a newly compiled library. This release distributes source only and uses the
explicit rebuilt-library mode. Original certificate source/binary hashes are
preserved; the historical binary identity is not silently replaced.

Seikh uses independently implemented integer224 and MPFR256 arithmetic paths.
Qin's standalone replay checker shares its C++ model/interval kernel and MPFR/GMP
with generation. Neither workflow is a proof-assistant proof or a proof of
compiler, library, source-transcription or source-to-binary correctness. Positive
cover bounds certify only their explicitly declared domains and winner/order
events. Diagnostic finite-point tests are not mathematical proofs of identities.
