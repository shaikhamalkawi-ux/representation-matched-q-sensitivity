# Case 4 provenance — Seikh & Mandal 2023

Primary source: Mijanur Rahaman Seikh and Utpal Mandal, “q-Rung Orthopair Fuzzy Archimedean Aggregation Operators: Application in the Site Selection for Software Operating Units”, *Symmetry* 15(9), 1680. DOI 10.3390/sym15091680.

The executable input uses the normalized matrix printed in Section 6, Eq. (6) entropy weights, the algebraic special case of the q-ROFAWA operator (f(t)=log(t) / standard q-ROFWA form), q=4 baseline, and the paper's published aggregate and score values.

The full scale is not valid below q=4 because the matrix contains (0.8,0.8), making this a useful case where a higher rung is genuinely required for admissibility.

The entropy stage is explicitly raw-coordinate dependent; therefore this case is **not** claimed to have theorem-guaranteed controlled invariance. The controlled ranking is an empirical result, while the drift in controlled entropy weights is retained as evidence of residual method dependence.
